# Solana Privacy Rings Programs

This repository is a collection of programs that can be used with Solana Privacy Rings.

1. **[Shared Key Storage](shared-key-storage/)**

   Stores encrypted shared viewing key records for multisig or smart accounts.

   - **Audited** — No
   - **Released** - No
   - **Status** — SDK only; no custom program
   - **Program** — the SPL Record program, `recr1L3PCGKLbckBqMNcJhuuyU1zgo8nBhfLVsJNwr5` on Devnet and Mainnet
