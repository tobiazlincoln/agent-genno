# spr-tvc

Attested decryption for Solana Privacy Rings (SPR). A sender can pay a Solana
address before its owner registers a shielded wallet. The owner signs each
decrypt batch. The enclave encrypts the reply to a key generated by the
recipient wallet. The transfer publishes the recipient's Solana address as its
owner tag.
